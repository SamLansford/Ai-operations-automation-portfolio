What about retries, security, concurrency and rollback?

To check replay, submit the same message again without editing it: it reuses the request ID. Changing the message starts a new request, so it does not test an ID conflict.

Authentication failures, competing decisions, database isolation, forced model errors and transaction rollback require dedicated test tools. They cannot be honestly reproduced by a message example. The portfolio Evidence page explains their recorded inputs and assertions. Do not interrupt services, alter workflows or submit real customer information to force a failure.
